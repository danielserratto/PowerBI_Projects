# 📊 Sales Pipeline Performance Dashboard
## 📌 Project Overview
Developed a comprehensive Power BI dashboard to visualize and manage sales pipeline data from Salesforce. The tool enables tracking of top deals, stage progression, forecasting, and rep performance across regions and products.
It features dynamic filters, historical comparisons, and deal movement analysis to help sales teams identify risks, uncover trends, and make data-driven decisions — all within a clean, interactive interface.

## 🖼️ Dashboard Preview
Snapshot of top deals with details such as their current sales stage, quarter, and value. It also includes seller-level summaries across all stages, the full reporting hierarchy, and deal health status (at risk, needs attention, or on track). Dynamic filters allow users to explore data by forecast category, weighted or unweighted values, product, deal size, and owner (opportunity, account, or partner).
