# 📊 Sales Pipeline Performance Dashboard

## 📌 Project Overview

Developed a comprehensive Power BI dashboard to visualize and manage sales pipeline data from Salesforce. The tool enables tracking of top deals, stage progression, forecasting, and rep performance across regions and products.

It features dynamic filters, historical comparisons, and deal movement analysis to help sales teams identify risks, uncover trends, and make data-driven decisions—all within a clean, interactive interface.

## 🖼️ Dashboard Preview by Seller, Opportunity, and Quarter

Snapshot of top deals with details such as their current sales stage, quarter, and value. It also includes seller-level summaries across all stages, the full reporting hierarchy, and deal health status (at risk, needs attention, or on track). Dynamic filters allow users to explore data by forecast category, weighted or unweighted values, product, deal size, and owner (opportunity, account, or partner).

## 📊 Deals Movement

It compares the current state of the open pipeline to a previous point in time (e.g., last week or the start of the quarter), showing what changed: deals pushed forward or backward, closed won or lost, deleted, resized, newly created, or carried in from other quarters. Each movement type is drillable, and links to Salesforce allow users to explore deal history in detail.

## 📊 Quarterly Comparison

This view compares the current pipeline against both the previous quarter and the same quarter from the previous year. It highlights growth or decline across sales stages (e.g., Secure, Validate, Qualified) and allows dynamic segmentation by subregion, deal size, territory, or product, with charts updating accordingly.

## 📊 Pipeline Evolution and Top Deals

Shows total deal values by sales stage for each sales rep, including won, lost, and closed amounts. It also features a unique table that tracks top deals over time, displaying changes in stage, quarter, or value compared to the previous week or the start of the quarter, helping users understand how key opportunities have evolved.
